# Released class notebooks

This folder is the post-class notebook archive for CSCI 171. Each instructor notebook is published only after its scheduled class has ended, normally later that same day. Future notebooks are intentionally unavailable.

During class, students work in their own blank Google Colab notebook and enter code through the live lab. After class, a released notebook can be opened here for review. Its **Open in Google Colab** badge opens the instructor copy; use **File → Save a copy in Drive** to keep a separate personal reference copy.

The repository root [README](../README.md) contains the complete meeting schedule.
