# CSCI 171 — Introduction to Python — Student Practice Notebooks

**Author:** Proma Roy  
**Term:** Fall 2026

This repository distributes post-class instructional notebooks for the in-person CSCI 171 live-lab course. The course schedule contains 27 public notebook releases across 29 scheduled meetings: the Oct. 20 midterm and Dec. 15 final evaluation use private materials and therefore have no public practice notebook.

Each notebook combines concise reference notes, intentional-error investigation, guided coding, additional in-class code practice, independent practice, and reflection. Spoken explanation and live demonstrations are provided during class.

Every notebook uses the same learning rhythm:

**analogy → prediction → intentionally wrong attempt → observation → repair → guided practice → independent practice → exit ticket**

## Google Colab course workflow

Google Colab is the standard notebook environment for this course. No local Python, Jupyter, or virtual-environment installation is required. Students need a working Google account, Google Drive access, a current browser, and internet access.

During class, open a new blank notebook directly in Google Colab, save it in the course Google Drive folder, and enter and test code as directed during the live lab. The completed instructor reference notebook is not available before or during that meeting.

After class ends, the instructor notebook is published in the [course repository](https://github.com/HeyPromaRoy/csci-171-introduction-to-python) under its [`notebooks/`](notebooks/) folder. Use the meeting link below, select its **Open in Google Colab** badge, and choose **File → Save a copy in Drive** if a personal reference copy is wanted. A notebook opened from the repository never overwrites the notebook used during class.

Read the complete [Google Colab and Google Drive Guide](COLAB_GUIDE.md) before Meeting 2.

## Release and reading policy

- Each public class notebook is published **after its scheduled class has ended**, normally later that same day.
- No completed instructor notebook is published before or during class. A future meeting link remains unavailable until the post-class release.
- During class, students create or open their own blank Colab notebook and enter code through the live lab rather than copying completed repository material.
- Weekly readings are assigned separately through **Brightspace**. They are not bundled into this repository.
- Brightspace remains the source for weekly announcements, readings, graded work, rubrics, deadlines, submission instructions, feedback, and schedule changes.

## How to use a released notebook after class

1. After the class has ended, use the meeting list below to select the released notebook.
2. On that notebook's GitHub page, select its **Open in Google Colab** badge.
3. Save a personal Drive copy if the notebook will be annotated, rerun, or completed after class.
4. Compare it with the code and notes created during the live lab.
5. Revisit predictions, intentional errors, repairs, and additional practice without replacing the student's original work.
6. Confirm that any personal Drive copy is saved before closing the browser.

## Scope guardrails

These materials focus on the syllabus core: computing foundations, notebooks, variables, input/output, decisions, loops, functions, strings, lists, dictionaries, tuples, sets, text/CSV files, exceptions, and basic summaries. Recursion, lambda expressions, classes, pandas, NumPy, and machine learning are outside the required scope.
