# Homework assignments

This folder collects the individual homework assignments for CSCI 171 that supplement the notebook labs and the four graded Programming Assignments described in the syllabus. Each assignment is a self-contained Colab notebook that students copy to their own Google Drive, complete, and submit through Brightspace.

| Assignment | Covers | Assigned after | File |
|---|---|---|---|
| Homework 1 | Meeting 1 (Computers, Programs, Python, and Google Colab), Meeting 2 (Your First Google Colab Notebook), and Meeting 3 (Variables and Basic Data Types) | Meeting 2 (2026-09-03) | [01_computers_colab_and_variables_preview.ipynb](01_computers_colab_and_variables_preview.ipynb) |

## Notes

- Due dates, grading weight, and submission mechanics are set on Brightspace, per the course syllabus; this repository only distributes the assignment content.
- Each assignment notebook includes its own submission checklist and an AI-use disclosure section, consistent with the syllabus's academic-integrity policy.
- These homework assignments are distinct from the four graded Programming Assignments (worth 5% each) listed in the syllabus's grade breakdown.
